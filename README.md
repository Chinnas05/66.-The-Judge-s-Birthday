# 66. The Judge's Birthday

Interactive modular-grid murder mystery built with Vite, vanilla JavaScript and GSAP.

## Run
```bash
npm install
npm run dev
```

Then open the Vite URL (normally http://localhost:5173/).

## Structure
- `index.html` — page shell
- `src/main.js` — suspects, clues, mansion, interactions and verdict logic
- `src/style.css` — modular-grid visual system and responsive layout
- `package.json` — Vite + GSAP dependencies

## Theme
The interface uses recognizable cinema/superhero-inspired character names and faceless illustrated portraits. The supplied clue set is retained in the interactive experience.

## Customize
Edit the `suspects` array in `src/main.js` to change names, clue text, portrait colors, or the final solution.
